# Karachi Civic Compass

Create a modern, premium and fully responsive web application called CivicConnect – Smart Citizen Complaint & Tracking System.

Project Purpose:

CivicConnect is a civic engagement platform designed for Karachi, Pakistan. It helps citizens report everyday community problems such as damaged roads, overflowing garbage, broken streetlights, water leakage and drainage issues. Citizens can submit complaints, track their progress and see how community problems are being addressed.

Design Direction:

Create a beautiful, professional, modern SaaS-style interface. The design should look like a real startup product, not a basic university assignment.

Visual guidelines:

Clean white and very light grey backgrounds.

Deep navy blue as the primary color.

Vibrant blue accents for buttons and interactive elements.

Modern typography such as Inter.

Rounded cards with subtle shadows.

Beautiful icons and clean illustrations.

Spacious layouts and excellent visual hierarchy.

Fully responsive on desktop, tablet and mobile.

Create the following pages:

HOME PAGE

Professional navigation bar with CivicConnect logo.

Hero section with headline: "Together, Let's Build Better Communities."

Supporting text explaining the platform.

Primary button: "Report an Issue".

Secondary button: "Track Complaint".

Display community statistics using sample data.

Show complaint categories with attractive icons.

Include a How It Works section.

Include a footer.

CITIZEN DASHBOARD

Welcome message.

Total complaints submitted.

Resolved complaints.

Pending complaints.

Recent complaint activity.

Button to submit a new complaint.

REPORT A COMPLAINT

Complaint category selection.

Complaint title.

Detailed description.

Photo upload area.

Location input.

Submit complaint button.

Display a success message with a unique sample complaint ID after submission.

TRACK COMPLAINT

Search field for complaint ID.

Complaint details.

Current status.

Visual progress timeline showing Submitted, Under Review, In Progress and Resolved.

Show complaint location and submission date.

ADMIN DASHBOARD

Total complaints.

Pending complaints.

Complaints in progress.

Resolved complaints.

Complaint management table.

Category filters.

Department assignment option.

Complaint status update controls.

Analytics charts.

Important Functional Requirements:

Add working navigation between all pages.

Make buttons and forms interactive.

Use realistic sample data for demonstration.

Allow users to submit demo complaints.

Allow admin to update complaint statuses.

Make submitted complaints appear in the dashboard and tracking page.

Use browser-side demo storage if necessary.

No real government integration is required.

Clearly treat all sample complaints and statistics as demonstration data.

Final Goal:

Create a polished, realistic and presentation-ready CivicConnect web application that I can demonstrate during my university Civics and Community Engagement project presentation.

Prioritize excellent UI design, smooth user experience and a professional visual appearance. Do not make it look like a generic template.
